# Baja Inventory Manager
 
A lightweight inventory and stock management system designed for small businesses.
 
## Features
 
- Product Management
- Inventory Tracking
- Low Stock Alerts
- Sales Tracking
- Dashboard Analytics
- CSV Export
- Mobile Friendly
 
## Tech Stack
 
- React
- Node.js
- SQLite
- GitHub
